# Lapaas AI Course Assistant

Helps visitors understand whether Lapaas’s AI Product Engineering course suits their goals.

## Features

- Seven-question guide with personalised course-fit guidance.
- AI chat for custom course questions.
- Answers based on verified course information.
- Clearly identifies details that need confirmation.
- Responsive design for desktop and mobile.

Built with HTML, CSS, JavaScript and Node.js, with AI responses through the NVIDIA API.

Official course: https://cohort.lapaas.com/
